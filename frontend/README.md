# GlucoRisk

GlucoRisk is an explainable machine-learning screening platform for estimating the likelihood of elevated A1C based on simple health and lifestyle inputs. The project combines a trained model, a FastAPI backend, and a Next.js frontend into a single workflow for interactive screening and API-based inference.

## What this project does

GlucoRisk helps users explore a screening-style risk estimate using inputs such as:

- age
- BMI
- waist circumference
- blood pressure
- physical activity
- sedentary time
- sleep duration
- smoking status

The app returns a probability-based risk score, a screening interpretation, and a brief recommendation. It is designed as an educational tool and not a diagnosis.

## Project overview

- Backend: FastAPI service for model inference and health checks
- Frontend: Next.js web app for collecting user input and displaying results
- Modeling: Python scripts and notebooks for data preparation, training, validation, and model promotion
- Data: processed and raw NHANES-style datasets plus saved model artifacts

## Architecture

- [api/main.py](api/main.py) exposes the prediction API and health endpoint
- [frontend/src/app/page.tsx](frontend/src/app/page.tsx) provides the main UI experience
- [src/](src/) contains data preparation and training workflows
- [models/](models/) stores the trained model and metadata
- [tests/test_api.py](tests/test_api.py) covers the core API behavior

## Quick start

### 1. Prerequisites

Make sure you have:

- Python 3.10+ recommended
- Node.js 20+ recommended
- pip

### 2. Create and activate a Python environment

From the project root:

```bash
python -m venv .venv
source .venv/Scripts/activate
pip install -r requirements.txt
```

### 3. Run the API backend

```bash
uvicorn api.main:app --reload --host 0.0.0.0 --port 8000
```

The API will be available at:

- http://localhost:8000/
- http://localhost:8000/docs
- http://localhost:8000/health

### 4. Run the frontend

Open a second terminal and run:

```bash
cd frontend
npm install
npm run dev
```

Then open http://localhost:3000 in your browser.

## Example API request

```bash
curl -X POST "http://localhost:8000/predict" \
  -H "Content-Type: application/json" \
  -d '{
    "age": 45,
    "bmi": 29.5,
    "waist_cm": 100,
    "avg_systolic_bp": 132,
    "avg_diastolic_bp": 84,
    "recreation_met_minutes_week": 600,
    "sedentary_minutes": 480,
    "average_sleep_hours": 7,
    "smoking_status": 0
  }'
```

## Notes and disclaimer

This project is intended for educational screening and research purposes. The predictions are generated by a trained statistical model and should not be treated as medical advice or a diagnosis. For any health concerns, please consult a qualified healthcare professional.
